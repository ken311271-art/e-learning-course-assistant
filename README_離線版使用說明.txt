E 等公務員學習助手 - HTML GUI 離線版

使用方式
1. 將整個 ZIP 解壓縮到一般資料夾，不要直接在壓縮檔內執行。
2. 確認電腦已安裝 Google Chrome。
3. 雙擊「離線啟動.bat」或「E等公務員學習助手.exe」。
4. 第一次使用請啟動瀏覽器並登入，之後 Session 會保存在同資料夾的 user_data_chrome。

離線範圍
- 已包含 Python、PySide6、Qt WebEngine、Playwright 與程式資源。
- 程式不會下載 Python 套件或瀏覽器。
- 網站操作本身仍需要網路連線。
- 依照既有設定，本壓縮檔不內附 Google Chrome。

注意事項
- EXE 與 _internal 資料夾必須放在一起，請勿只複製 EXE。
- 請勿在程式執行時移動或刪除資料夾。
- 若 Windows 顯示安全提示，請確認檔案來源後選擇仍要執行。
- 發生錯誤時請查看 logs\app.log。
