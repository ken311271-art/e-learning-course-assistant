E 等公務員學習助手 - ZIP 版

首次使用：
1. 先安裝 Python 3.12 以上。
2. 先安裝 Google Chrome。
3. 解壓縮 ZIP。
4. 執行 install.bat。
5. 執行 run.bat。

搬到其他電腦時：
- 不會包含 user_data、user_data_chrome、logs、build、dist、__pycache__。
- 因此不會帶走原本電腦的登入 Session。
- 第一次在新電腦仍需登入一次，之後同一資料夾會保存 Session。

常用檔案：
- main.py：程式入口。
- requirements.txt：Python 套件需求。
- resources/course_schedule.json：上課排程設定。

注意：
- 若 install.bat 找不到 py，請確認 Python 安裝時有勾選 Add Python to PATH。
- 若 Chrome 未安裝，請先安裝 Google Chrome。
